# Blind scoring rubric (100 points)

The judge gets: the case file, this rubric, the answer key, and three outputs labelled X, Y and Z
in random order. The judge is not told which tool produced which output.

Score each output on its own, then compare.

1. Accuracy of facts and citations (30 points). Check every factual statement in the support
   letter against the case file. Minus 5 for each invented fact. Minus 2 for each wrong exhibit or
   page citation. Minus 1 for each factual statement with no citation.
2. Traps handled (30 points). Items 6 to 16 in the answer key: about 2.7 points each, given only if
   the output clearly leaves the item out, downgrades it or explains it correctly.
3. Gaps flagged (15 points). Items 17 to 20: points if each is clearly flagged as missing or weak.
4. Criteria chosen correctly (15 points). Items 1 to 5 claimed with the right evidence, and no
   weak criterion claimed as met. Minus 3 for each wrong claim.
5. Legal frame and usefulness (10 points). Names the right regulation and the two step final
   merits review; a lawyer could edit it into a filing without restructuring it.

Write the score for each section, the total, and the three most serious problems in each output.

# Demo case: O-1A for Lena Varga (made up)

Everything in this folder is invented for testing: the people, companies, prizes, publications,
universities, figures and documents. Any resemblance to real people or organisations is
accidental. No client files, no real cases.

Purpose: week 1 of `docs/TEST-PLAN.md`. The same case file goes to three preparers:

* A: plain Claude (a fresh chat at claude.ai, prompt in `prompt.md`)
* B: plain ChatGPT (a fresh chat, same prompt)
* C: Lincoln's step by step method (`lincoln/`)

The outputs are then judged blind (labels shuffled) against `rubric.md`.

The case contains deliberate traps a careful preparer should catch. They are listed in
`answer-key.md`. Do not give that file to any preparer or judge until scoring is done.
